# Repository work

This repository distributes `skills/chatgpt-codex-network`. Keep that directory self-contained: installed users may have only that folder, without this file or the repository README.

For a diagnosis or repair, follow its `SKILL.md` and the applicable platform reference. For usage records and contributions, follow [the feedback workflow](skills/chatgpt-codex-network/references/feedback.md). Include unresolved failures as observed results.

Improve the narrow decision or helper responsible for a demonstrated problem. Keep host-specific settings in incident evidence rather than promoting them to defaults. Preserve the distinction between configuration snapshots, fixture evaluations and native application acceptance.

Use the verification command in README after script changes, and add a regression check for the demonstrated behavior. For instruction changes affecting a decision branch, exercise a realistic scenario and record what was actually evaluated in `evals/RESULTS.md`. Use a skill-format validator when available. Keep references resolvable from the installed folder.

Keep usage records, captures, credentials and personal configuration outside the Git checkout. Stage only the intended source, sanitized fixtures and reviewable documentation. Present feedback as an Issue or a branch/PR according to the workflow and the user's current authorization.
